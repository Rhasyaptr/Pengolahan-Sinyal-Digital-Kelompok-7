05 — TEORI

Teori dan alur kerja

Rumus yang dipakai aplikasi dan urutan pemrosesannya.

DCT-II (maju)

X(k) = α(k) · Σ x(n) · cos[ π/N · (n + ½) · k ] n, k = 0 … N−1 α(0) = √(1/N), α(k>0) = √(2/N)

N = 256 sampel. Koefisien ke-k mewakili k/2 siklus per jendela. Faktor α(k) membuat basis ortonormal, sehingga energi sinyal terjaga (teorema Parseval).

IDCT (balik)

x(n) = Σ α(k) · X(k) · cos[ π/N · (n + ½) · k ] Filter: X′(k) = X(k) jika k < K, selain itu 0 MSE = (1/N) · Σ [ x(n) − x′(n) ]²

Dengan matriks basis, satu transformasi butuh N² = 65.536 perkalian (O(N²)). Karena basisnya ortonormal, MSE sama dengan jumlah kuadrat koefisien yang dibuang dibagi N.

Mengapa DCT?

  • Basis hanya cosinus, nilainya real, tanpa bilangan kompleks.
  • Ekstensi simetris menghilangkan lonjakan di batas blok.
  • Energi menumpuk di koefisien rendah, sehingga sisanya bisa dibuang. Dasar kompresi JPEG dan MP3.

Kode inti (JavaScript)

// Matriks basis DCT-II ortonormal, dihitung sekali
const C = new Float64Array(N*N);
for (let k = 0; k < N; k++) {
  const a = k ? Math.sqrt(2/N) : Math.sqrt(1/N);          // α(k)
  for (let n = 0; n < N; n++) C[k*N+n] = a * Math.cos(Math.PI/N * (n + .5) * k);
}
// DCT: X = C·x          IDCT: x = Cᵀ·X
function getDCT(x)  { /* X[k] = Σ_n C[k][n]·x[n] */ }
function getIDCT(X) { /* x[n] = Σ_k C[k][n]·X[k] */ }

// Filter: pertahankan K koefisien pertama, nolkan sisanya
const rec = getIDCT(getDCT(sig).map((v, i) => i < K ? v : 0));
const mse = sig.reduce((s, v, i) => s + (v - rec[i]) ** 2, 0) / N;
